# Chethan Swamy N - Portfolio Website

## Upload to GitHub
1. Open the `portfolio` repository.
2. Select **Add file > Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, the `assets` folder and the `documents` folder.
4. Commit the files.
5. Open **Settings > Pages**.
6. Select **Deploy from a branch**, branch **main**, folder **/(root)** and save.

## Before publishing
- Open `index.html` and replace the generic LinkedIn URL with the exact LinkedIn profile URL.
- Review the downloadable CV and remove any information that should not be public.
- Do not upload confidential drawings, internal reports, client documents, home address, passport data or membership numbers.
